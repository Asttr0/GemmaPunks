# MIZAN Souq design system

- Style: trustworthy, data-dense operations dashboard.
- Background: slate `#0f172a`; panel `#172033`; border `#334155`.
- Primary: amber `#f59e0b` for trust and merchant actions.
- AI accent: violet `#8b5cf6`; never imply that an AI action is confirmed.
- Success: emerald plus a text label; warning: amber plus a text label.
- Typography: system/Inter with Noto Sans Arabic fallback; tabular monospace for
  prices and quantities.
- Motion: 150–250 ms state transitions and reduced-motion support.
- Layout: mobile-first; bottom navigation below 1024 px and sidebar above it.
- Interaction: 44 px minimum targets, visible focus rings, semantic controls.
- Data: currency always includes MAD; charts require a text/table alternative.
